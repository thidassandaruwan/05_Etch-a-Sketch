Instructions

  1. Select Press & Hold so that board only register mouse movements when the left mouse button is pressed.
  2. Select Erase to uncolor cells
  3. Press Clear to clear out entire drawing board.
  4. Press Resize to customise the drawing board gridsize. Only numbers from 10 - 100 are accepted.
  5. Select Automatic Multi-Color to draw using randomly generated multiple colors for each pixel.
  6. Press Random Color to generate a random color which will be shown in the color sample section
  7. Feel free to choose a color from the color picker.
